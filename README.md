# 🎵 音楽制作スタジオ (Kids Beat Maker)

ブラウザを開くだけですぐに使える、子供向け（小学生〜）の直感的な音楽制作アプリ（DAW）です。 専門知識がなくても、マス目を「ポチポチ」と塗るだけで誰でも簡単にオリジナル曲を作ることができます。プログラミング教育やクラブ活動の教材として最適です。

## ✨ 主な機能 (Features)

*   **直感的なステップシーケンサー**:
    
    *   メロディトラック（8音階）とリズムトラック（キック・スネア・ハイハット）を搭載。なぞり入力にも対応。
        
*   **絶対にリズムが狂わないAudio Engine**:
    
    *   商業用DAWと同じ「Lookahead Scheduling」を採用し、ブラウザ上で正確なリズム再生を実現。
        
*   **魔法のサウンド設定**:
    
    *   4種類の音階（長調、短調、琉球、祭囃子）と7種類の楽器音（ピアノ、オルゴール、8bit、ギターなど）をボタン一つで切り替え。
        
    *   空間を彩る「反響（ディレイ）」「残響（リバーブ）」エフェクト搭載。
        
*   **AI一発作曲機能 (AI Composer)**:
    
    *   ChatGPTやGeminiなどの生成AIに読み込ませる「専用プロンプト」を内蔵。AIが生成したJSONコードを読み込むことで、イメージ通りの曲が一瞬で完成します。
        
*   **MP3エクスポート機能**:
    
    *   作成した曲を、指定したループ回数でMP3ファイルとしてダウンロード可能。動画のBGMなどにも使えます。
        
*   **子供に優しい安心設計**:
    
    *   すべての漢字に「ふりがな（ルビ）」付き。
        
    *   初回起動時のインタラクティブな「ガイドツアー」搭載。
        
    *   変更するたびにブラウザに自動保存されるオートセーブ機能。
        
*   **完全レスポンシブ対応**:
    
    *   PC、タブレット、スマートフォンのどの画面サイズでも快適に操作可能。
        

## 🚀 使い方 (Usage)

1.  **音を置く**: 画面右側のマス目をクリック、またはなぞって色を塗ります。
    
2.  **再生する**: 左上の「再生」ボタン（またはスペースキー）を押して音楽を聴いてみましょう。
    
3.  **音を変える**: 左側のパネルから「音階」や「楽器」を変えたり、「やまびこ」のチェックを入れて響きを変えたりできます。
    
4.  **保存する**: 自動保存されていますが、「MP3出力」ボタンを押すと、音声ファイルとしてパソコンに保存できます。
    

### 🤖 AI作曲機能の使い方

1.  左下の「AI作曲」ボタンをクリックします。
    
2.  モーダル内の「AIへの指示（プロンプト）をコピー」ボタンを押します。
    
3.  お好きな生成AI（ChatGPT, Claude, Geminiなど）を開き、コピーした文章を送信します。
    
4.  AIから「どんなイメージの曲を作りたいですか？」と聞かれるので、「宇宙を探検するような曲」「明るくて元気な曲」など自由に答えます。
    
5.  AIが出力した `JSONコード` をコピーし、アプリの読み込み欄に貼り付けて「魔法で曲を生成！」ボタンを押せば完成です。

## 🛠️ 技術スタック (Tech Stack)

*   **Frontend**: React, Tailwind CSS, Lucide React (Icons)
    
*   **Audio**: Web Audio API (Oscillator, BiquadFilter, Convolver, Delay, WaveShaper)
    
*   **Export**: lamejs (MP3 Encoding)
    
*   **Architecture**: 単一ファイルコンポーネント (Single File React App)
    

## 💻 開発者向け (Getting Started)

このアプリケーションは、外部サーバーやデータベースを必要としない完全なスタンドアロン形式で設計されています。

`App.jsx` 1ファイルにすべてのロジックが含まれており、Viteなどのビルドツールを使用して即座にGitHub Pagesへデプロイ可能です。

```bash
# クローン
git clone https://github.com/GIGAyama/Music-production_studio.git
cd Music-production_studio

# 依存関係のインストール
npm ci

# 開発サーバーの起動
npm run dev

# 本番ビルド（dist/ に出力）
npm run build
```

`main` ブランチへの push で GitHub Pages へ自動デプロイされます（`.github/workflows/deploy.yml`）。

## 🔐 セキュリティ設計（扱うデータ／扱わないデータ）

### 扱わないデータ

このアプリは**サーバーを持ちません。** 以下は一切収集も送信もしません。

*   氏名・学年・クラス・出席番号などの個人情報（入力欄そのものがありません）
*   メールアドレス、アカウント情報（ログイン機能がありません）
*   アクセス解析、Cookie、広告トラッキング

コード中に `fetch` / `XMLHttpRequest` の使用箇所は **0件**です。作った曲がネットワークに出ていくことはありません。

### 扱うデータ

ブラウザの **localStorage** に、以下の2つのキーだけを保存します。**その端末の中だけ**に残ります。

| キー | 内容 |
|---|---|
| `kidsBeatMakerData_master` | 作曲データ（音符の配置、BPM、音階、楽器、エフェクト、小節名） |
| `kidsBeatMaker_tutorialCompleted` | ガイドツアーを見たかどうかのフラグ |

*   別の端末やシークレットウィンドウで開くと、曲は引き継がれません
*   ブラウザの閲覧データを削除すると曲も消えます
*   共用端末では**1つの曲しか保存できず、後から使った児童が上書きします**
*   残したい曲は「MP3出力」でファイルに保存してください

### 外部との通信

| いつ | 通信先 | 必須か |
|---|---|---|
| 常時（画面表示） | `fonts.googleapis.com`（日本語フォント） | 任意。届かなくても標準フォントで表示されます |
| **MP3出力を押したときのみ** | `cdnjs.cloudflare.com`（MP3変換ライブラリ `lamejs`） | **必須**。届かないとMP3出力だけが失敗します |
| ユーザーがボタンを押したとき | `chatgpt.com` / `gemini.google.com` / `claude.ai` を新しいタブで開くだけ | 任意 |

> ⚠️ **既知の課題**：MP3変換ライブラリを外部CDNから読み込んでおり、SRI（改ざん検知）も
> Content-Security-Policy も未設定です。校内フィルタで遮断されると出力機能が使えません。
> 自己ホスト化が今後の改善予定です（詳細は [`AUDIT.md`](./AUDIT.md)）。

### AI作曲機能について

このアプリは生成AIに接続していません。児童（または先生）が、AIのサイトとこのアプリの間で
テキストをコピー＆ペーストして運ぶ方式です。**AIのサイトへ何を送るかは利用者の操作次第**であるため、
授業で使う際は、児童が個人情報を打ち込まないようご指導ください。

## ⚠️ 制限とできないこと

| 項目 | 制限 |
|---|---|
| 曲の長さ | 最大4小節（16ステップ × 4 = 64ステップ） |
| メロディの音域 | 8音（音階によって異なる） |
| リズム | 3種類（ハイハット / スネア / キック） |
| 同時に保存できる曲 | **1曲のみ**（曲名を付けて複数保存する機能はありません） |
| 保存の範囲 | その端末・そのブラウザの中だけ。クラウド同期なし |
| 読み込めるファイル | なし（MP3は書き出し専用。読み込みはできません） |
| MP3出力 | インターネット接続が必要。長い曲＋多いループ回数では数十秒かかります |
| 音が出る条件 | ブラウザの仕様上、**画面を1回クリック／タップするまで音は鳴りません** |
| 動作環境 | Chrome / Edge / Safari の新しめの版。Web Audio API に対応していない古い端末では動きません |
| 復旧 | 保存データが壊れると起動時に画面が真っ白になります（[`MANUAL.md`](./MANUAL.md) の「うまくいかないとき」に対処法あり） |
